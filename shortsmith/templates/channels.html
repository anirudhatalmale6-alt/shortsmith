Google OAuth is not configured yet

This is a one-off, about five minutes. The credentials stay on your server and belong to your own Google account.

  1. Open console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. APIs & Services → OAuth consent screen. Pick External, fill in the app name and your email, and add yourself under Test users.
  4. Add these scopes: youtube.upload, youtube.readonly, youtube.force-ssl.
  5. Credentials → Create credentials → OAuth client ID → Web application.
  6. Under Authorised redirect URIs add exactly:
    {{ redirect_uri }}
  7. Copy the client ID and secret into your .env as GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET, then restart.

Two things Google does that look like bugs

Everything uploads as private. Until your Google Cloud project passes YouTube's API audit, every upload made through the API is forced to private and scheduled publish times are ignored. The upload works; the video just never goes public. Request the audit from the YouTube API services page once you are happy with the setup.

Six uploads a day. The default API quota is 10,000 units a day and one upload costs 1,600, so a fresh project gets about six videos a day across all channels. Ask for more quota in the Cloud Console if you need a bigger run rate.
